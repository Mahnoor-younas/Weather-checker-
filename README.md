# 🌤️ Weather Checker App

A clean, responsive weather application that lets users instantly look up real-time weather conditions for any city around the world.

---

## 🛠️ Technologies

- `HTML5`
- `CSS3`
- `JavaScript (ES6+)`
- `OpenWeatherMap API`
- `Fetch API`
- `Git & GitHub`

---

## ✨ Features

Here's what you can do with Weather Checker:

- **Search Any City:** Type any city name and instantly get live weather data from around the world.

- **Temperature Display:** View the current temperature in both Celsius and Fahrenheit with a single click.

- **Humidity & Wind Speed:** Get detailed atmospheric conditions including humidity percentage and wind speed.

- **Dynamic Weather Icons:** Icons automatically update to reflect current weather — sunny, cloudy, rainy, and more.

- **Error Handling:** If a city is not found or the network fails, a friendly error message is shown to the user.

- **Responsive Design:** Works smoothly on all screen sizes — desktop, tablet, and mobile.

---

## ⚙️ The Process

I started by setting up the basic HTML structure with an input field and a search button. Then I styled the UI using CSS to make it look clean and visually appealing with a card-based layout.

Next, I connected the app to the OpenWeatherMap API using JavaScript's Fetch API. I made sure the app sends the correct request with the city name and API key, then receives and displays the weather data dynamically.

To improve the user experience, I added dynamic weather icons that change based on the current weather condition. I also handled edge cases like invalid city names and network errors so the user always gets a clear message.

Finally, I focused on making the app fully responsive so it works well on both mobile and desktop screens. I tested it with multiple cities to make sure everything displayed correctly and consistently.

## 🚀 Running the Project

To run the project in your local environment, follow these steps:

1. Clone the repository to your local machine.
2. Open the project folder.
3. Add your own API key in `script.js` where it says `YOUR_API_KEY`.
4. Open `index.html` in your browser to view the app — no build step needed!
